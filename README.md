# مكتبة صغار الباحثين · Young Researchers' Library

مكتبة بحثية حقوقية بالعربية تجمع:
- المعايير الدولية لحقوق الإنسان
- الآليات الأممية والإقليمية
- الاجتهادات والقرارات
- فهرسة الموارد حسب الحق
- ملف تونس
- التقارير الحقوقية حول تونس منذ 2020

الموقع ثابت بالكامل ويعمل على GitHub Pages دون خادم.

## بنية الملفات

```
index.html              الصفحة الوحيدة (الواجهة)
assets/css/style.css    التصميم
assets/js/app.js        البرمجة: التوجيه، البحث، الفلاتر، المفضلة، الإحالات، التصدير
data/meta.json          الأقسام، أنواع الوثائق، اللغات، مواضيع التقارير، الجهات الناشرة، صفحات المتابعة
data/resources.json     المواقع وقواعد البيانات
data/documents.json     الوثائق: معاهدات، تعليقات عامة، ملاحظات ختامية، أحكام، آراء، تشريعات…
data/reports.json       الأبحاث والتقارير حول تونس
data/rights.json        الفهرسة حسب الحق (البنية السداسية)
data/tunisia.json       الخط الزمني وقائمة الملاحظات الختامية لتونس
data/guides.json        أدلة «كيف أبحث؟»
data/aliases.json       مرادفات البحث بالعربية والفرنسية والإنجليزية
data/glossary.json      معجم المصطلحات ومسار «تعلّم المنظومة»
tools/validate.py       فحص البيانات قبل النشر
tools/check_links.py    فحص الروابط
```

المحتوى كله في ملفات `data/`. لإضافة وثيقة أو تقرير لا تحتاج إلى لمس `index.html` أو `app.js`.

## إضافة تقرير جديد حول تونس

1. افتح `data/reports.json` على GitHub، ثم اضغط زر القلم (Edit).
2. انسخ أي تقرير موجود، وألصقه بعد القوس `[` في أول الملف مباشرة، ثم ضع فاصلة بعده.
3. عدّل الحقول:

```json
{
 "id": "rep-amnesty-2026-example",
 "publisher": "amnesty",
 "date": "2026-10-15",
 "year": 2026,
 "type": "report",
 "title_orig": "العنوان الأصلي كما نشرته المنظمة",
 "title": "ترجمة عربية للعنوان",
 "topics": ["detention", "judiciary"],
 "summary": "ملخص من سطرين أو ثلاثة.",
 "lang_orig": "en",
 "langs": ["en", "ar", "fr"],
 "url": "https://رابط صفحة التقرير",
 "pdf": "https://رابط ملف PDF إن وُجد",
 "pages": 40,
 "note": "",
 "scope": "tn",
 "checked": "2026-10-20",
 "added": "2026-10-20"
}
```

قيم الحقول:
- **id:** فريد، بحروف لاتينية صغيرة وأرقام وشرطات فقط.
- **publisher:** أحد مفاتيح `publishers` في `data/meta.json`، مثل `hrw` و`amnesty` و`icj` و`omct` و`rsf` و`fidh`. لإضافة جهة جديدة، أضفها هناك أولًا: الاسم بالعربية، والاسم الأصلي، ورابط صفحتها حول تونس.
- **type:** واحد من:
  - `report` (تقرير بحثي)
  - `briefing` (ورقة إحاطة أو تحليل قانوني)
  - `submission` (تقرير مقدَّم إلى آلية)
  - `statement` (بيان)
  - `annual` (فصل من تقرير سنوي)
- **topics:** من مفاتيح `topics` في `meta.json`:
  - `civil`
  - `judiciary`
  - `detention`
  - `torture`
  - `expression`
  - `assembly`
  - `defenders`
  - `esc`
  - `women`
  - `migrants`
  - `discrimination`
  - `environment`
- **date:** بصيغة `YYYY-MM-DD`، أو `YYYY-MM` إن لم يُعرف اليوم.
- **year:** يجب أن تطابق السنة الواردة في `date`.
- **langs:** رموز اللغات، مثل `ar` و`en` و`fr` و`it`.

تظهر السنة الجديدة تلقائيًا في صفحة التقارير، دون أي تعديل في الواجهة.

**قاعدة المكتبة:** لا تُضاف وثيقة لم يُتحقَّق من وجودها على موقع الجهة الناشرة. افتح الرابط بنفسك قبل الإضافة، وسجّل تاريخ ذلك في `checked`.

## إضافة وثيقة (تعليق عام، حكم، رأي، تشريع…)

أضف عنصرًا إلى `data/documents.json`:

```json
{
 "id": "gc-ccpr38",
 "title": "حرية تكوين الجمعيات (المادة 22)",
 "type": "gc",
 "body": "CCPR",
 "number": "38",
 "publisher": "اللجنة المعنية بحقوق الإنسان",
 "publisher_en": "UN Human Rights Committee",
 "date": "2026",
 "year": 2026,
 "symbol": "CCPR/C/GC/38",
 "url": "https://docs.un.org/ar/CCPR/C/GC/38",
 "langs": ["ar", "en", "fr", "es", "ru", "zh"],
 "articles": ["22"],
 "rights": ["assembly"],
 "sections": [["treaty", "التعليقات العامة"]],
 "scope": "global",
 "status": "",
 "summary": "",
 "checked": "2026-11-02",
 "added": "2026-11-02"
}
```

قيم الحقول:
- **type:** من `doc_types` في `meta.json`. هذا النوع يحدد تلقائيًا القيمة القانونية المعروضة: ملزم، أو تفسيري، أو غير ملزم، أو بحثي. لا تخلط بين الأنواع.
- **symbol:** رمز الأمم المتحدة. إن وُجد، تُبنى منه تلقائيًا روابط النسخ العربية والفرنسية والإنجليزية والإحالات.
- **rights:** معرّفات الحقوق من `data/rights.json`، مثل `expression` و`torture` و`migration`.
- **sections:** القسم والمجموعة التي تظهر فيها الوثيقة. أسماء المجموعات موجودة في `meta.json`.
- **status:** للتنبيه، مثل «مشروع» أو «تحقّق من اعتماده». احذفه بعد التأكد.

لعرض الوثيقة داخل صفحة حق، أضف معرّفها إلى إحدى قوائم ذلك الحق في `data/rights.json`:
- `interp`: للتفسيرات
- `soft`: للمعايير غير الملزمة
- `regional`: للمعايير الإقليمية

يمكن أيضًا الاكتفاء بحقل `rights` في الوثيقة نفسها. في هذه الحالة تظهر الوثيقة في:
- البحث
- الوثائق المرتبطة
- قسم الاجتهادات (للأحكام والآراء)
- قسم التوصيات (للملاحظات الختامية)
- قسم التطبيقات الوطنية (للتشريعات)

## قبل كل نشر

```bash
python3 tools/validate.py
```

يكشف هذا الأمر:
- المعرّفات المكررة
- التواريخ الخاطئة
- الحقول الناقصة
- الإحالات إلى وثائق غير موجودة

## فحص الروابط (مرة كل شهر مثلًا)

```bash
python3 tools/check_links.py            # تقرير في tools/link-report.csv
python3 tools/check_links.py --update   # ويحدّث تاريخ التحقق للروابط السليمة
```

بعض مواقع الأمم المتحدة ترفض الفحص الآلي. افتح الروابط المعلَّمة يدويًا قبل حذف أي رابط.

## التشغيل على جهازك

المتصفح يمنع قراءة ملفات البيانات عند فتح `index.html` مباشرة، لذلك شغّل خادمًا محليًا من مجلد المشروع:

```bash
python3 -m http.server 8000
```

ثم افتح http://localhost:8000. على GitHub Pages يعمل الموقع مباشرة.

## النشر على GitHub Pages

1. ارفع محتوى هذا المجلد كما هو إلى جذر المستودع: `index.html` و`assets/` و`data/` و`tools/` و`.nojekyll` و`README.md`. ملف `.nojekyll` يمنع GitHub من معالجة الملفات.
2. في إعدادات المستودع افتح Settings، ثم Pages، واختر Deploy from a branch، ثم `main`، ثم `/ (root)`.

الرابط القديم للموقع لا يتغير. الروابط الداخلية القديمة تُحوَّل تلقائيًا إلى أماكنها الجديدة، مثل `#tunisia` و`#r-expression` و`#howto`.

## المفضلة وقوائم البحث

تُحفظ في متصفح كل مستخدم على جهازه، ولا تُرسل إلى أي خادم. من صفحة «قوائمي» يمكن:
- نسخ الإحالات بأنماط Chicago أو OSCOLA أو Bluebook أو النمط العربي
- تصدير القائمة بصيغ Word (.doc) أو CSV أو BibTeX

## التوسع لاحقًا

- **اللغات:** نصوص الواجهة الثابتة مجمّعة في الكائن `UI` وقائمة `NAV` أعلى `assets/js/app.js`. أما المحتوى فيكفي فيه إضافة حقول مثل `title_fr` إلى البيانات.
- **البحث داخل نصوص PDF:** يتطلب استخراج النصوص مسبقًا إلى ملف فهرس (`data/fulltext.json`) يُبنى بسكربت خارجي. البنية الحالية تسمح بإضافته دون تغيير الواجهة.

## بيانات المنظمة (صفحة «عن المكتبة»)

في `data/meta.json` املأ الحقل `org` ليظهر اسم المنظمة وموقعها وبريدها في صفحة «عن المكتبة» وفي عمود «تواصل» أسفل كل صفحة (يبقى العمود مخفيًا ما دام الحقل فارغًا):

```json
"org": {"name": "اسم المنظمة الرسمي", "url": "https://موقع-المنظمة", "email": "contact@example.org"}
```

## شارة «جديد»

كل وثيقة أو تقرير يكون تاريخ إضافته (`added`) بعد تاريخ `launch` في `meta.json` وخلال آخر 30 يومًا تظهر عليه شارة «جديد» تلقائيًا.

## المعجم ومسار التعلّم

`data/glossary.json` فيه قسمان: `terms` للمصطلحات (`id`، `term`، `en`، `fr`، `def`، و`see` رابط داخلي اختياري، و`types` إن كان المصطلح يشرح نوع وثيقة فيظهر تعريفه عند المرور على شارة النوع) و`learn` لخطوات مسار التعلّم.

## روابط البحث القابلة للمشاركة

كل بحث بفلاتره يُحفظ في الرابط، مثل `#search?q=تعذيب&type=gc`، ويمكن إرساله لزميل ليفتح النتائج نفسها.

## الصفحة الرئيسية

- **شبكة الحق في أعلى الصفحة:** تُبنى تلقائيًا من `data/rights.json` لكل حق: أول نص ملزم دولي في `legal`، وأول تفسير في `interp`، وأول آلية في `mechanisms`، وعدد التقارير حول تونس المرتبطة به. الحقوق المرتبطة (`related`) تظهر على أطراف الشبكة ويمكن النقر عليها لاستكشافها.
- **الحقوق المقترحة تحت الشبكة:** القائمة `HERO_PICKS` في أول قسم «home» داخل `assets/js/app.js`.
- **مجموعات فهرس الحقوق:** كل حق في `rights.json` يحمل الحقل `group`، وأسماء المجموعات في `right_groups` داخل `meta.json`. عند إضافة حق جديد أعطه `group` موجودًا، وإلا يظهر تحت «حقوق أخرى».
- **الخطوط:** العناوين بخط Amiri والنصوص بخط IBM Plex Sans Arabic، وتُحمَّل من Google Fonts في `index.html`.
